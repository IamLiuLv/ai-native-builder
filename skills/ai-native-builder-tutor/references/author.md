# 联系作者

小册作者：**lv.liu**，需求交付工程师，在 AI Native 团队工作。

## 什么时候引导读者联系作者

- 小册里**没有讲到**的问题（见 `faq.md` 末尾「小册没有讲、常被问到的」）；
- 需要**真实经验判断**的问题：自己的项目、团队、职业选择；
- 读者发现小册里有**错误、过期数据或讲得不清楚**的地方；
- 读者想**继续交流、获取后续实践**。

## 怎么写引导语

简短、具体，告诉读者**带着什么去问**，不要写成广告：

```markdown
这个问题和你们团队的具体情况关系很大，小册里没法给出结论。
可以直接问作者 lv.liu：在 [交个朋友](https://iamlv.cn/friends) 页面扫码加他微信（`lvjishupai`，备注「AI Native」），
带上你们团队的规模、现在的流程，以及卡在哪一步，会更好聊。
```

不要：

- 不要在小册能回答的问题后面也附上联系方式；
- 不要主动推销课程。只有读者明确问到「有没有现成的完整方案」「作者是怎么搭出来的」「课程」时，才给课程链接，一句话带过，说清楚这是作者的付费课程。

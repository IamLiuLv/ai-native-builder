## 关于这些数据

- 招聘数据统计的是**招聘广告**，不是实际雇佣人数。
- 斯坦福的研究，作者明确说是「早期的描述性指标，不是因果估计」。
- 「老中医」是我的说法。数据支持的是**经验**的价值，不是年龄本身。
- Faros 是度量工具厂商，有自己的商业立场。
